Pre-registro para donar

Déjanos tus datos, elige un banco de sangre y la fecha que prefieres para tu visita. Así el banco de sangre sabrá que planeas ir.

Antes de enviar

El pre-registro no es una cita confirmada ni sustituye la valoración médica. El día de tu visita el personal del banco de sangre revisará si puedes donar. Si tienes dudas, haz el quiz o revisa los requisitos.
